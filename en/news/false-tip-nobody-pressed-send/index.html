A false murder tip, and nobody pressed send

Anthropic has cut internet access from all its internal tests: its models had filled in real forms, dodged fees and exploited flaws on outside websites. The report says less than the headlines on some points, and more on others.

The headline that went around

Anthropic's AI breaks into US government websites, files twenty visa applications and sends police a fake murder tip.

What the document says

On October 9 Anthropic, the company that makes Claude, published a report on actions its models took on the web that nobody had planned for. Almost all of them happened during evaluations: tests in which a model repeats the same task hundreds or thousands of times, often connected to the internet, because some tasks, like searching the web for a hard-to-find fact, cannot be done without it. The company says it found them by reviewing transcripts from July onward.

The report sorts them into four groups. In one, Claude Mythos Preview had to run a scientific analysis with a tool hosted by a university. The tool returned an error; the model found a script on the server that would return any file, read its code, found a flaw in it and used the flaw to run commands on the server and do the calculation. In another, Claude Mythos 5 read the settings file of a local government's property map, found working access tokens and used them to query the server directly. In a similar case it avoided the fee a state agency charged for public data. Finally, several models used free URL-shortening services to get around a limit Anthropic had deliberately put on its own tools.

The group that made the headlines is the one about forms. Claude Haiku 4.5 had to invent and carry out example tasks on randomly chosen web pages. One was the page of an unsolved homicide, with a tip form run by the police. Its instructions forbade creating accounts, entering personal data or making purchases, but not submitting forms. The model wrote: “I recall seeing someone matching the description in the area around [the street named on the page] during that time period.” The page contained no description. It left the name and contact fields empty and submitted. The form flagged it as spam, and it never reached investigators. According to the report, the transcript suggests the model was only producing example content for the task, not trying to mislead anyone.

The twenty visas are not in the report. The report describes an unreleased research model meant to fill in a practice copy of a government form: when the copy failed to load, it went to the real site and submitted there. The rest came from the US State Department, speaking to reporters: nineteen visa applications in August and one in May, incomplete, never processed, and no system compromised. The Philadelphia Police Department confirmed the form was theirs, submitted on July 18, and called it “unacceptable” that the company only told them in October.

Anthropic calls the impact “minimal” and writes that these behaviors do not change its overall view of Claude. Meanwhile it has switched off live internet access in all internal evaluations, not just cybersecurity ones, until it has confirmed that its new controls catch cases like these. It also acknowledges that its alignment training is “not yet sufficient” to make models handle ambiguous or impossible tasks with care, the ones where, instead of stopping, they look for a way around the obstacle.

What we don't know

How many cases there really are. The report is not a census: the transcript review continues, and Anthropic says it will report new cases as they come.

Which sites and which agencies. Anthropic does not name them, at their request and to avoid exposing the flaws. The ones we know, Philadelphia police and the State Department, we know because they said so themselves.

Whether the model lied about its actions in any case. Anthropic writes that it has not completed a full assessment, and that its view may change.

When the tests will go back online. The report says “until” the controls work reliably, but not how that will be measured.
